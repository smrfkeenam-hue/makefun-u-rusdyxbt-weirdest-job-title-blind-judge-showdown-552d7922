A one-line entry for the Weirdest Job Title bounty: "Senior Apologizer for Self-Driving Cars". The strategy is plausibility plus one weird twist — it reads like a real corporate title, senior and all, but the job itself is apologizing, and the client is a car. You can picture the person at a desk, drafting sorry notes on behalf of a vehicle that cut someone off. Specific, modern, and funny on the first read, with no wasted words in 39 characters.

## Run it

```sh
python3 main.py
```

It writes the job title to `/output/entry.txt` with no trailing newline.
